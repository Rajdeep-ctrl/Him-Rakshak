# HIM-RAKSHAK
---

## 🌟 Key Features

1. **GIS Interactive Risk Map:** Built with React Leaflet featuring custom risk-severity pins, layer toggles, and detail drawers with AI explainability metrics.
2. **Dual Operational Data Modes:** Instant toggle between **MOCK DATA** mode for off-line hackathon demonstrations and **LIVE API** mode targeting future FastAPI endpoints.
3. **Multilingual Interface:** Fully reactive translations for English, Hindi (हिन्दी), and Assamese (অসমীয়া).
4. **Hazard Reporting:** Client-side hazard submission tool with browser Geolocation acquisition and media drag-and-drop previews.
5. **Early Warning Incident Feed:** Real-time severity filters, detail modals, and emergency dispatch action workflows.
6. **Corridor Vulnerability Monitoring:** Status tracking for vital regional highways (NH-27, NH-29, Shillong-Sohra route).

## 🚀 Quickstart & Local Setup

### Prerequisite
* Node.js v18+ 
* npm v9+

### Installation
```bash
# Clone repository
git clone <YOUR_REPOSITORY_URL>
cd him-rakshak-frontend

# Install dependencies
npm install

# Copy environment variables
cp .env.example .env

# Run development server
npm run dev
